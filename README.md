# 🕸️ Product Information Web Scraper

A Python-based web scraper that extracts product details such as product name, price, and rating from a website and stores the data in a CSV file.

## 🚀 Features

* Extracts product information from webpages
* Fetches product names, prices, and ratings
* Stores scraped data into a CSV file
* Beginner-friendly implementation
* Uses HTML parsing techniques

## 🛠 Technologies Used

* Python
* BeautifulSoup
* Requests
* CSV File Handling

## ▶️ How to Run

Install required libraries:

```bash id="x1w9be"
pip install requests beautifulsoup4
```

Run the program:

```bash id="ptk5v9"
python product_scraper.py
```
